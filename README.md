# Mini Event Scheduler

A modern full-stack event scheduling application with AI-powered categorization, built using React (Vite, TypeScript, Tailwind CSS) for the client and Node.js/Express/MongoDB for the server.

---

## Live Demo

- **App:** [https://event-scheduler-theta.vercel.app/](https://event-scheduler-theta.vercel.app/)
- **API Health:** [https://event-scheduler-server-2x3q.vercel.app/api/v1/health](https://event-scheduler-server-2x3q.vercel.app/api/v1/health)

---

## Features

- Create, view, and manage events with title, date, time, location, notes, and category.
- AI-based automatic categorization (Work, Personal, Other).
- Filter events by date, category, and time (upcoming, past, today).
- Responsive design with sidebar and mobile drawer.
- RESTful API with MongoDB storage.

## Project Structure
